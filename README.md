주의사항

본 패치는 USA Uncensored 전용입니다. 일본판이나 다른 버전에는 사용할 수 없습니다.

번역 및 패치 제작 과정에서 원작의 용어와 캐릭터 말투를 최대한 살리는 것을 목표로 작업했습니다. 아직 발견하지 못한 오탈자나 표시 문제가 있을 수 있으니 제보 부탁드립니다.
